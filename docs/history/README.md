# Build history (superseded)

These reports were written during the original phase-by-phase build (Phases 14 to 25,
up to June 2026). Several of them declare the system complete or production ready;
the audits that followed found that it was not, and Repairs 1 to 15 rebuilt and
verified the system. They are kept only as a record of how the build went.

The source of truth for what is built, how it was tested and what remains is
`BUILD_LEDGER.md` at the repository root.
